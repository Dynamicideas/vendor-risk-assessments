# Third-Party Vendor Risk Management Portfolio

## Project Focus
This repository serves as a professional portfolio illustrating the end-to-end processing of **Third-Party Risk Management (TPRM)** and **Vendor Governance**. It demonstrates the capacity to intake vendor documentation (SOC 2 Type II, SIG, ISO certifications), extract core control deficiencies, and draft executive-level risk mitigation blueprints.

## Skills Showcased
* **SOC 2 Type II Analysis:** Reading independent auditor opinions, identifying testing exceptions, and analyzing Section IV system descriptions.
* **Qualitative Risk Evaluation:** Compiling Threat/Vulnerability tables mapping Likelihood and Impact metrics.
* **Governance Drafting:** Authoring conditional vendor approval metrics featuring actionable engineering restrictions (e.g., Network IP Whitelisting, Key Management).

## Portfolio Structure
* `SAR_SaaS_Vendor_XYZ.md`: A live simulation of an enterprise security evaluation analyzing a cloud architecture vendor.
